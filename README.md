# 🎬 Netflix Movie Recommendation System

Machine Learning-based Netflix Movie Recommendation System using Collaborative Filtering and SVD Algorithm in Python.

---

# 📌 Project Overview

This project builds a personalized movie recommendation system similar to Netflix using Machine Learning techniques and Collaborative Filtering.

The recommendation engine analyzes user rating behavior and predicts movies users are likely to enjoy.

---

# 🚀 Features

- Personalized movie recommendations
- Collaborative Filtering recommendation system
- SVD (Singular Value Decomposition) algorithm
- Exploratory Data Analysis (EDA)
- User rating behavior analysis
- Recommendation prediction system
- Data preprocessing pipeline

# ⚙️ Machine Learning Workflow

## 1. Data Collection
Loaded Netflix movie rating dataset.

## 2. Data Preprocessing
- Cleaned dataset
- Removed unnecessary values
- Prepared user-item matrix

## 3. Exploratory Data Analysis
Analyzed:
- Rating distribution
- Most active users
- Most popular movies
- User behavior patterns

## 4. Recommendation System
Built recommendation engine using:
- Collaborative Filtering
- Singular Value Decomposition (SVD)

## 5. Prediction
Generated personalized movie recommendations for users.

---

# 📈 Key Insights

- Most users provide ratings between 3 and 5.
- Popular movies receive significantly higher engagement.
- Collaborative filtering improves recommendation personalization.
- SVD effectively predicts user preferences.
